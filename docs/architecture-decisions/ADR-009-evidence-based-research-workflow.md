# ADR-009: Evidence-Based Research Workflow & Reliable Research Output

## Status
Accepted

## Context
In automated AI investment research, hallucination and generic fallback content create unacceptable risks. Previously, if an LLM returned malformed JSON or incomplete output, fallback mechanisms risked manufacturing generic claims (e.g. "Long-term growth potential", "General equity risk") that were not directly traceable to actual financial evidence. Furthermore, factual financial metrics (prices, multiples, revenue, debt) must not be generated by LLM arithmetic.

## Decision
1. **Fact vs. Analysis Separation in `ResearchReport`**:
   - `facts`: Factual metrics (`current_price`, `pe_ratio`, `forward_pe`, `market_cap`, `profit_margins`, `total_debt`, `sector`, `industry`) are pre-fetched directly from `FinancialDataService` and attached to the report without LLM manipulation.
   - `fundamentals`, `valuation`, `market_context`, `risks`, `opportunities`: Analytical conclusions derived by AI reasoning over verified ground-truth facts.
2. **Elimination of Fabricated Fallbacks**:
   - Removed silent generic fallback generation in `ResearchService._parse_crew_output()`.
   - Malformed or unparseable LLM output raises a clear exception (`ValueError`), resulting in a standardized safe error response (`INTERNAL_SERVER_ERROR`) rather than returning fabricated financial claims under HTTP 200.
3. **Traceable Source Provenance**:
   - `sources` in `ResearchReport` is assembled directly from authenticated `SourceMetadata` objects attached to financial entities (`CompanyProfile`, `MarketQuote`, `KeyMetrics`, `HistoricalPrices`, `NewsArticle`).
   - The LLM is barred from inventing citations or external URLs.
4. **Structured Pre-Fetched Research Context**:
   - Verified financial data is provided directly to the CrewAI prompt so agents analyze verified facts rather than hallucinating statistics.
5. **Multi-Tenant User Isolation Preserved**:
   - Personal memory context remains strictly scoped to `g.current_user.id` from JWT authentication. Client-provided `user_id` continues to be completely ignored.

## Consequences
- **Positive**: 100% of factual metrics and citations are traceable to verified financial data providers.
- **Positive**: Zero hallucinated generic financial fallback reports.
- **Positive**: Clean failure modes when external LLM providers produce malformed outputs.
